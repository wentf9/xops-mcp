# 控制台与 MCP 客户端

[English](../en/user/console.md) · [使用指南](README.md)

## 管理员登录

首次打开页面时，填写管理员用户名、密码和初始化码。密码为 12–72 个 UTF-8 字节，不能包含换行或空字符。常见中文字符通常占 3 个字节；确认密码必须完全一致。

登录有效期为 15 分钟，同一标签页刷新后可继续使用。新标签页需要登录。退出会清除当前标签页的登录状态；修改密码后，旧密码不能再次登录，但已经登录的其他页面会在原有效期结束后失效。重启服务不会提前结束有效登录。

在“账户”页面修改密码。忘记密码时使用[离线重置](maintenance.md)。

## 添加可用节点

1. **主机与信任**：添加 SSH 地址和端口，打开“配置公钥”。选择连接获取公钥，或输入从主机控制台等可信渠道取得的公钥。
2. **核对公钥**：通过独立渠道核对指纹，再确认固定。未确认的公钥不会自动用于连接。每次确认预览有效两分钟；改变地址或公钥后重新预览。
3. **凭据**：添加远端登录密码或 SSH 私钥。私钥带有口令时同时填写。保存后不再回显；编辑时留空表示保留原内容。
4. **登录身份**：填写 SSH 用户名并关联凭据。
5. **节点总览**：关联主机、身份和标签，按需要设置跳板、提权方式，然后启用。连接测试只验证 SSH 登录，不执行命令。

只能通过跳板访问的主机可先“输入已独立核验的公钥”，再选择有序跳板。跳板顺序从本服务到目标；停用某个跳板也会阻止依赖它的节点连接。

主机、身份、凭据、节点和标签名称，以及节点别名，支持文字、字母、十进制数字、下划线和连字符，长度为 1–256 个 UTF-8 字节。空格、其他标点、emoji 和不可见字符不能使用。同类名称须唯一，节点别名每行一个。

## 标签、策略和审计

标签可独立创建、重命名或删除。删除标签只移除关联，不删除节点。节点、主机、身份或凭据仍被引用时，需要先解除关联才能删除。

“操作策略”用于设置需要确认的风险级别、禁止的命令模式和受保护路径。客户端不能完成确认时，默认拒绝需要确认的操作。

“运行中”显示当前操作；“审计记录”可按节点和结果筛选。审计不保留原始命令、文件路径或密码。修改被其他页面抢先保存时，当前页面会提示冲突；刷新后重新编辑即可。

修改地址不会把已经开始的工作切换到新目标。停用节点、更新凭据或撤销公钥可能中止相关操作；已开始的远程文件写入仍需核对结果。如果页面提示配置已经保存但尚未应用，使用“重试应用”，不要重复提交同一修改。

## 连接 MCP 客户端

在支持 Streamable HTTP 的 MCP 客户端中配置：

| 项目 | 内容 |
| --- | --- |
| 连接类型 | Streamable HTTP |
| 服务地址 | 例如 `http://127.0.0.1:8080/mcp` |
| 访问凭据 | 在 [MCP Token](tokens.md) 页面创建时复制的完整 Token |

需要手动填写请求头的客户端使用：

```text
Authorization: Bearer <创建时复制的 Token>
```

每个客户端使用独立的 Token。不要填写管理员密码、初始化码或管理登录密钥，也不要连接管理页面的端口或路径。

连接后先查询节点列表，再选择节点执行命令。可用操作包括命令执行、文本读写、目录和文件管理、上传及下载。以客户端实际显示的工具为准。

上传和下载时，本地文件位于客户端设备。目录需要先打包成文件；单文件上限为 10 GiB。下载完成后还需确认客户端保存成功。服务重启或网络中断后出现“结果未知”的任务时，按[维护指南](maintenance.md#文件任务结果未知)处理，不要直接重复上传覆盖目标。
